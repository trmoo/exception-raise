# 🥤 부숴봐! 자판기 3차시 — raise

> © 2026 티쳐무 · 모든 권리 보유 — 학교 수업 목적으로만 이용해 주세요. ([LICENSE](LICENSE))

예외 처리 1·2차시(「부숴봐! 자판기」 — try·except·else·finally) 다음 시간에 쓰는 앱입니다.
지난 시간에 만든 **방어막 자판기**는 예외 5종을 모두 막지만, **파이썬이 오류라고 여기지 않는 값** 앞에서는
멈추지도 않고 틀리게 팝니다(-1번에 주스, 사람 수 -2명이면 한 명당 -600원 …).
학생은 이런 고장을 찾아낸 뒤, **규칙을 세우고 어기면 `raise` 로 예외를 일으켜** 지난 시간의 `except` 가 잡게 만듭니다.
선생님은 **교사 대시보드**에서 반 전체의 진행과 「가장 많이 막힌 곳」을 실시간으로 봅니다.

- 대상: 고등학교 「정보」·「프로그래밍」 파이썬 — 예외 처리 3차시 (`raise` · `except … as e` · 🏆 맞을 때까지 다시 묻기 `while`·`break`)
- 한 화면에 한 가지만 — 화면이 1280×720 카드 한 장이라 **교실 TV·노트북 어디서나 스크롤이 없습니다**
- 파이썬 설치 없이 브라우저에서 진짜로 실행됩니다 (진짜 파이썬 3.12 와 출력·오류 문구를 대조해 맞췄습니다)
- 학생은 맨 처음 **학번 · 이름 · 비밀번호**로 로그인하고 자리 번호를 고릅니다. 선생님 시트에만 남고, 발표 화면에는 이름을 가립니다(홍*동).
  비밀번호는 알아볼 수 없게(솔트 + SHA-256 해시) 숨긴 `계정(비밀번호)` 시트에만 저장되어 선생님도 볼 수 없습니다

## 카드 차례 (15장)

| 단원 | 카드 |
|---|---|
| 시작 | ① 로그인(학번 → 이름·비밀번호) → ② 자리 번호 고르기 |
| 멈추지 않는 고장 | 🔍 **고장 찾기** — 지난 시간의 방어막 자판기에 값을 넣어 「멈추지 않는데 틀린」 고장 4가지를 도감에 모은다 (막히면 💡 힌트를 하나씩) → except 로는 왜 못 잡을까? |
| raise | `raise ValueError("…")` 예제 (17 · -3 · 열일곱) → 내가 일으킨 예외도 except 가 잡는다 · `as e` 로 메시지 꺼내기 → **if 로도 되는데 왜 raise 일까?** (같은 값으로 A `if`+`print` · B `if`/`else` · C `raise` · D 함수 안에서 — 네 판을 견준다) |
| 규칙 세우기 | 🛡️ 미션 1 번호 규칙 (`raise IndexError`) → 🛡️ 미션 2 사람 수 규칙 (`raise ValueError` + `except ValueError as e`) |
| 🏆 끝판왕 | 🔁 맞을 때까지 다시 묻기 예제(`while True:` + `try` + `else: break`, 「열일곱, -3, 17」 처럼 쉼표로 여러 값) → 🏆 **끝판왕 미션** — 몇 번이고 틀리는 「끈질긴 손님」 3명을 끝까지 받아 판다 (감사 인사는 반복 밖에서 한 번만) |
| 확인 문제 | 4문항 → 🏁 오늘의 결과 (「오늘 배운 것」은 학생이 직접 적고 **📤 선생님께 제출하기**) |

도감의 고장 4가지 — 🔄 뒤에서 파는 자판기(-1번) · ➖ 거꾸로 돈을 주는 자판기(사람 수 -2) ·
🆓 공짜 자판기(사람 수 2000 → 한 명당 0원) · 🪙 돈이 모자란 자판기(1200원을 7명 → 3원 모자람).


← → 키나 아래쪽 단추로 넘깁니다. 오른쪽 위 **🧹 기록 초기화** 를 누르면 이 기기의 활동 기록을 모두 지우고 처음부터 시작합니다
(선생님께 이미 보낸 기록은 남습니다).

## 교사 대시보드

웹 앱 주소 끝에 `?page=teacher` 를 붙여 열고 교사 암호를 넣습니다.

- **🆕 새 수업** — 반 이름(예: 「2-3 반」)을 정하면 학생 시작 카드에 그 수업이 뜹니다.
  같은 반이 다음 시간에 이어서 할 때는 새 수업을 만들지 말고 📚 수업에서 그 반을 골라 「▶ 이 수업 이어서 하기」.
- **📺 발표** (TV 에 띄워 함께 봄) — 우리 반이 찾은 「멈추지 않는 고장」 4장과 첫 발견 · 순위 · 방금 소식.
- **🔍 선생님** — 학생마다 찾은 고장·미션·확인 문제 · 미션별 통과 수 · **가장 많이 막힌 곳**(예: 「미션 2 사람 수 규칙 — 공짜 자판기 못 막음」) · 확인 문제 정답률.
- **✍️ 정리** — 학생이 제출한 **「오늘 배운 것」** 을 물음별로 모아 봅니다. TV 에 띄울 때는 **🙈 이름 가리기**.
- **📚 수업** — 지난 수업을 골라 다시 볼 수 있습니다.

## 설치 (선생님, 처음 한 번 · 10분)

```bash
npm install
npm run pack      # dist/appsscript/ 에 붙여 넣을 파일 4개가 생긴다
```

1. 구글 시트를 새로 만들고 **확장 프로그램 → Apps Script** 를 엽니다. (1·2차시 앱과는 **다른 시트**를 쓰세요)
2. `Code.gs` 내용을 지우고 `dist/appsscript/Code.gs` 를 붙여 넣습니다.
3. **파일 + → HTML** 로 `index` 파일을 만들고 `dist/appsscript/index.html` 을 붙여 넣습니다.
4. ⚙️ 프로젝트 설정 → 「appsscript.json 매니페스트 파일 표시」 를 켜고 `appsscript.json` 을 붙여 넣습니다.
5. 저장 → 시트를 새로고침하면 메뉴 **🥤 부숴봐! 자판기 3차시** 가 생깁니다.
   **① 시트 준비하기 → ② 교사 암호 정하기** (처음 한 번 권한 승인).
6. **배포 → 새 배포 → 웹 앱** — 실행: **나**, 액세스: **모든 사용자**.
7. 나온 주소가 **학생 주소**, 끝에 `?page=teacher` 를 붙이면 **대시보드**입니다.

코드를 고친 뒤에는 **배포 관리 → ✏️ 수정 → 새 버전** 으로 바꿔야 주소가 그대로입니다.
편집기의 ▶ 단추로 실행할 것은 없습니다 — 시트 준비는 시트 메뉴로 합니다.

시트는 다섯 장입니다 — `수업` · `현황`(학생 한 명 = 한 줄) · `기록`(사건 한 줄씩, 학번만) ·
`오늘 배운 것`(학생 한 명 = 한 줄, 물음마다 한 열) · `계정(비밀번호)`(숨김).
**비밀번호를 잊은 학생**은 시트 메뉴 **「③ 학생 비밀번호 초기화」** 에 학번을 적어 주세요(활동 기록은 남습니다).
**학기가 끝나면 시트 메뉴 「기록 모두 지우기」 로 지워 주세요** (학생 계정까지 지웁니다).

한 반(30명 안팎)이 동시에 써도 됩니다. 접속이 몰려 실패하면 화면이 저절로 다시 시도합니다.
인터넷이 끊겼거나 서버 없이 쓰려면 `dist/index.html` 을 나눠 주세요. 더블클릭하면 「혼자 모드」로 그대로 됩니다.

## 개발

```bash
npm start              # 개발 서버 — 진짜 Code.gs 를 가짜 시트 위에서 돌린다 (교사 암호 teach1234)
npm test               # 시험 — 진짜 파이썬 대조 · 미션 채점 · 서버
npm run check:syntax   # 소스 전수 검사 (문법 · 저작권 · 화면 수명 · Code.gs)
npm run build          # dist/index.html 한 파일 (약 170KB)
npm run pack           # 위 + dist/appsscript/ (붙여 넣을 파일) + dist/gas-test.html
```

- 개발 서버를 켠 채 학생 주소와 `?page=teacher` 를 탭 두 개로 열면, 같은 가짜 시트를 나눠 써서 배포 없이 처음부터 끝까지 시험할 수 있습니다.
- `PYTHONUTF8=1 python tools/golden.py` — 해석기를 견줄 기준을 진짜 파이썬으로 다시 만듭니다. 자판기·미션·예제·확인 문제를 고치면 다시 돌리세요.
